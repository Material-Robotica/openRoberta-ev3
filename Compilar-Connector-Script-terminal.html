Windows 10/11 · Robótica · Alternativa al kit portátil

Compilar el Open Roberta Connector

Instala solo lo necesario (JDK 17 + Maven, si faltan) y compila el Connector con compilar-openroberta-connector.ps1. No instala Tomcat, VS Code ni extensiones.

📦 Releases del Connector 🧰 Entorno Java Web completo
01

Armar la carpeta recursos-connector

Crear la carpeta C:\recursos-connector con este contenido:

  • compilar-openroberta-connector.ps1 — el script va dentro de esta carpeta
  • El código fuente del Connector: el .zip Source code de la página de releases (no hace falta descomprimirlo) o la carpeta openroberta-connector\ clonada con git
  • El instalador .msi del JDK 17 (Eclipse Temurin) — solo si la PC no tiene Java 17
  • apache-maven-3.9.x\ — solo si la PC no tiene Maven

Si la máquina ya tiene Java 17 y Maven (por ejemplo, porque se le pasó el script del entorno Java Web), el script los detecta y no instala nada.

02

Abrir PowerShell como Administrador

Clic derecho sobre PowerShell en el menú Inicio → Ejecutar como administrador. Se necesita para instalar el JDK y agregar Maven al PATH del sistema.

03

Ubicarse en la carpeta

La ventana elevada arranca en otra carpeta por defecto:

cd C:\recursos-connector
04

Permitir la ejecución de scripts

Habilita la ejecución solo para esta ventana, sin cambiar la configuración permanente:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
05

Ejecutar el script

.\compilar-openroberta-connector.ps1 -RecursosPath "C:\recursos-connector"
+ DESTINO

Elegir dónde dejar el resultado

Por defecto queda en C:\OpenRoberta-Connector.

.\compilar-openroberta-connector.ps1 -RecursosPath "C:\recursos-connector" -Destino "D:\OpenRoberta-Connector"
NECESITA INTERNET

Maven descarga las dependencias del Connector la primera vez (unas decenas de MB). Con conexión lenta puede tardar varios minutos: esperar a que aparezca BUILD SUCCESS.

06

Revisar la salida y abrir el Connector

El script muestra las versiones de java y mvn y deja en la carpeta de destino:

C:\OpenRoberta-Connector\
├── OpenRobertaConnector.jar
├── libs\
└── Abrir Open Roberta.bat   doble clic para abrirlo

Para actualizar el kit portátil OpenRoberta-EV3: reemplazar el contenido de su carpeta connector\ por el de C:\OpenRoberta-Connector. El .bat del kit no se toca.

⚠ SI ALGO FALLA

"Se instaló el JDK pero 'java' no responde"

La ventana no tomó las variables nuevas. Cerrar PowerShell, abrir otra como administrador y repetir los pasos 03 a 05: el script detecta el JDK ya instalado y sigue.

La compilación falla

Casi siempre es la conexión (Maven no pudo bajar una dependencia). Volver a ejecutar el script: lo ya descargado queda en caché.
