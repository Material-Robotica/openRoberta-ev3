Guía de Programación en Java con Open Roberta Lab

Manual Didáctico para Estudiantes de 1.º de Bachillerato

Nivel: Bachillerato Plataforma: Open Roberta (LEGO EV3 / leJOS) Lenguaje: Java (POO)

1. Introducción y Configuración del Entorno

En Open Roberta Lab, el código visual en bloques (NEPO) se traduce directamente a código Java nativo. Esta guía permite a los estudiantes dar el salto conceptual hacia la programación textual en Java utilizando la capa de abstracción de hardware HAL (Hardware Abstraction Layer).

A. Programación en la Simulación Web

Para trabajar sin necesidad de un robot físico inmediato:

  • Ingresar a Open Roberta Lab.
  • Seleccionar el sistema LEGO EV3 (leJOS).
  • Hacer clic en la pestaña SIM del margen derecho para desplegar el simulador 2D.
  • Para ver o alternar al código en Java, presionar el botón de código </> en el menú superior.

B. Conexión con Robot Físico LEGO EV3

Para transferir y ejecutar el código Java en el bloque EV3 real:

  • El kit utiliza el firmware leJOS para ejecutar el código compilado de Java en el robot.
  • La conexión se establece mediante la aplicación ejecutable Open Roberta Connector.
  • El robot se conecta por USB y Windows le asigna la IP fija 10.0.1.1 a través del driver RNDIS.
Consejo pedagógico: Permite que los estudiantes depuren la lógica condicional primero en el simulador interactivo antes de descargar el programa al robot físico.

2. Estructura Base de un Programa Java

Todos los programas generados en la plataforma se compilan dentro de la clase principal NEPOprog. A continuación se muestra la plantilla estándar:

package generated.main;

import de.fhg.iais.roberta.runtime.*;
import de.fhg.iais.roberta.mode.sensor.*;
import de.fhg.iais.roberta.mode.action.*;
import de.fhg.iais.roberta.components.*;

public class NEPOprog {
    private static Configuration brickConfiguration;
    private static Hal hal;

    public static void main(String[] args) {
        try {
            brickConfiguration = new EV3Configuration.Builder().build();
            hal = new Hal(brickConfiguration, null);
            
            start(); // Punto de entrada a la lógica del estudiante
            
        } catch (Exception e) {
            Hal.showErrorMessage("Error en la ejecucion");
        }
    }

    public static void start() {
        // --- El código del alumno se escribe aquí ---
    }
}
Concepto clave: El objeto hal (Hardware Abstraction Layer) proporciona todos los métodos estandarizados para leer sensores y accionar motores.

3. Movimiento Básico: Adelante y Atrás

Para desplazar el robot se pueden controlar la velocidad (rango de $0$ a $100\%$) y la distancia o tiempo de marcha.

Ejemplo 1: Avanzar y Retroceder por Distancia Determinada

public static void start() {
    int velocidad = 50;        // 50% de potencia
    double distanciaCm = 30.0;  // 30 centímetros

    // Mover hacia adelante 30 cm
    hal.driveDistance(DriveDirection.FOREWARD, velocidad, distanciaCm);

    // Pausa de 1 segundo (1000 milisegundos)
    hal.waitFor(1000);

    // Mover hacia atrás 30 cm
    hal.driveDistance(DriveDirection.BACKWARD, velocidad, distanciaCm);
}

Ejemplo 2: Control Continuo por Tiempo

public static void start() {
    // Iniciar marcha continua hacia adelante
    hal.regulatedDrive(DriveDirection.FOREWARD, 60);
    
    // Mantener la marcha durante 2.5 segundos
    hal.waitFor(2500);
    
    // Detener el movimiento
    hal.stopRegulatedDrive();
}

4. Maniobras y Giros

En robótica móvil diferencial existen dos modalidades principales de giro:

  1. Giro Sobre su Eje (Pivot): Las ruedas giran en sentidos opuestos o una rueda permanece inmóvil.
  2. Giro Curvo: Ambas ruedas avanzan a velocidades diferentes.

Ejemplo 1: Giro por Ángulo Determinado

public static void start() {
    int velGiro = 40;

    // Giro de 90 grados a la izquierda
    hal.rotateDirectionRegulated(TurnDirection.LEFT, velGiro, 90);
    hal.waitFor(500);

    // Giro de 90 grados a la derecha
    hal.rotateDirectionRegulated(TurnDirection.RIGHT, velGiro, 90);
}

Ejemplo 2: Recorrido Cuadrado usando un Bucle for

public static void start() {
    int lados = 4;
    int velocidad = 50;
    double ladoCm = 25.0;

    for (int i = 0; i < lados; i++) {
        // Avanzar el lado del cuadrado
        hal.driveDistance(DriveDirection.FOREWARD, velocidad, ladoCm);
        hal.waitFor(200);

        // Girar 90 grados a la derecha
        hal.rotateDirectionRegulated(TurnDirection.RIGHT, 30, 90);
        hal.waitFor(200);
    }
}

5. Uso de Sensores

Resumen de llamadas para interactuar con los sensores en Open Roberta Java:

Sensor Puerto Típico Método Java en hal Tipo de Retorno
Táctil / Pulsador SensorPort.S1 hal.isPressed(SensorPort.S1) boolean
Ultrasonidos SensorPort.S4 hal.getUltraSonicSensorDistance(SensorPort.S4) float (cm)
Color / Luz SensorPort.S3 hal.getColorSensorSample(SensorPort.S3, ColorSensorMode.RED) float (0-100%)
Giroscopio SensorPort.S2 hal.getGyroSensorValue(SensorPort.S2, GyroSensorMode.ANGLE) float (grados)

A. Sensor Táctil (Detección de Colisión)

public static void start() {
    hal.regulatedDrive(DriveDirection.FOREWARD, 40);

    // Mantenemos el movimiento mientras NO se presione el pulsador
    while (!hal.isPressed(SensorPort.S1)) {
        hal.waitFor(50); // Pausa para liberar tiempo de CPU
    }

    // Al chocar: detenerse y retroceder
    hal.stopRegulatedDrive();
    hal.driveDistance(DriveDirection.BACKWARD, 30, 15.0);
}

B. Sensor de Ultrasonidos (Evasión de Obstáculos)

public static void start() {
    double umbralCm = 15.0;
    hal.regulatedDrive(DriveDirection.FOREWARD, 50);

    while (true) {
        float distancia = hal.getUltraSonicSensorDistance(SensorPort.S4);

        if (distancia < umbralCm) {
            // Esquivar obstáculo
            hal.stopRegulatedDrive();
            hal.rotateDirectionRegulated(TurnDirection.RIGHT, 40, 90);
            hal.regulatedDrive(DriveDirection.FOREWARD, 50);
        }
        hal.waitFor(50);
    }
}

C. Control Proporcional para Seguidor de Línea

Para seguir el borde de una línea negra con suavidad, se calcula el error con respecto al punto medio de luz reflejada $T = \frac{C_{\text{blanco}} + C_{\text{negro}}}{2}$: 

public static void start() {
    float puntoMedio = 50.0f; // Umbral medio
    float kp = 0.6f;          // Ganancia proporcional
    int velocidadBase = 30;

    while (true) {
        float luz = hal.getColorSensorSample(SensorPort.S3, ColorSensorMode.RED);
        float error = luz - puntoMedio;
        float correccion = error * kp;

        int velIzquierda = (int) (velocidadBase + correccion);
        int velDerecha   = (int) (velocidadBase - correccion);

        hal.regulatedDrive(ActorPort.B, ActorPort.C, velIzquierda, velDerecha);
        hal.waitFor(20);
    }
}

6. Proyectos Desafiantes para el Aula

Propuestas integradoras para evaluar algoritmos, condicionales y POO en 1.º de Bachillerato:

Proyecto 1: Explorador Autónomo

El robot avanza en un área delimitada. Si detecta un obstáculo a menos de $20\text{ cm}$ con el ultrasonido, emite una alerta, retrocede y selecciona de forma aleatoria girar a la izquierda o derecha.

Proyecto 2: Repartidor de Logística

Sigue una línea negra continua. Cuando el sensor detecta una marca de color rojo, se detiene durante 3 segundos para simular la descarga de mercancía y reanuda la ruta.

Proyecto 3: Resolutor de Laberintos

Implementar el algoritmo de la mano derecha utilizando el sensor de ultrasonidos lateral para mantener una distancia fija respecto a la pared mediante la fórmula de error $e = d_{\text{deseada}} - d_{\text{medida}}$.

7. Buenas Prácticas de Programación en Robótica

  • Nombres significativos y constantes: Declarar puertos y parámetros al inicio del programa para facilitar modificaciones en el aula. 
    final SensorPort PUERTO_ULTRASONIDO = SensorPort.S4;
final float DISTANCIA_UMBRAL = 20.0f;
  • Pausas en bucles continuos: Incluir siempre una pequeña pausa de refresco (ej. hal.waitFor(20);) dentro de los bucles while(true) para evitar saturar el procesador del robot o del simulador.
  • Salida de depuración: Utilizar System.out.println() para rastrear valores numéricos de los sensores en tiempo real durante las pruebas.
