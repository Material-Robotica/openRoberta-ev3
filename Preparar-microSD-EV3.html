Preparar la microSD del EV3

Instalar el firmware de Open Roberta (basado en leJOS) en una tarjeta microSD nueva. Solo hace falta si la tarjeta está vacía, dañada o se necesita una tarjeta extra.

ANTES DE EMPEZAR

Qué se necesita

Una sola vez por tarjeta.

  • Una tarjeta microSD de 2 a 32 GB (tipo SDHC). Las de más de 32 GB (SDXC) no funcionan en el EV3.
  • Un lector de tarjetas para la PC.
  • Una cuenta de Oracle (gratuita) para descargar Java.
  • El EV3 con las baterías cargadas: la instalación tarda y no se debe cortar.
PASOS

Armar la tarjeta

Todo se hace en la PC, salvo el último paso.

S1

Formatear la microSD en FAT32

Colocar la tarjeta en el lector. En el Explorador de archivos: clic derecho sobre la unidad → Formatear… → Sistema de archivos FAT32 → Iniciar.

Atención: formatear borra todo el contenido de la tarjeta.

S2

Descargar el firmware de Open Roberta

Descargar el archivo del firmware (versión 2.6.2, unos 34 MB):

OpenRobertaFirmware-2.6.2-release.zip

Descomprimir el .zip y copiar su contenido a la raíz de la microSD. Los archivos tienen que quedar sueltos en la tarjeta, no dentro de una carpeta.

S3

Descargar Java para el EV3

Entrar a la página de Oracle de Java para LEGO EV3 e iniciar sesión con la cuenta de Oracle:

Java SE Embedded para LEGO Mindstorms EV3

Elegir Java SE Embedded version 7 Update 60 → ARMv5 Linux - Headless (unos 32 MB). No elegir la versión 8.

ejre-7u60-fcs-b19-linux-arm-sflt-headless-07_may_2014.tar.gz
S4

Copiar Java a la tarjeta sin descomprimir

Copiar el archivo de Java tal cual a la raíz de la microSD, junto a los archivos del firmware. No descomprimirlo: el EV3 lo instala solo.

Verificar que el nombre termine en .tar.gz. Algunos navegadores lo descomprimen a medias y lo dejan como .tar; en ese caso, volver a descargarlo.

Expulsar la tarjeta de forma segura antes de sacarla del lector.

S5

Instalar en el EV3

Con el EV3 apagado, colocar la microSD en la ranura del costado del ladrillo. Encenderlo y esperar: la instalación tarda entre 10 y 15 minutos e incluye un reinicio automático.

No apagar el EV3 ni sacar la tarjeta durante ese tiempo. Queda listo cuando la pantalla muestra 10.0.1.1 y OpenRoberta Lab. A partir de ahí se sigue con la guía de puesta en marcha.

⚠ SI ALGO FALLA

El EV3 arranca con el sistema original de LEGO

  • La tarjeta no se está leyendo. Revisar que esté en FAT32, que sea de 32 GB o menos y que los archivos del firmware estén en la raíz y no dentro de una carpeta.

Se queda mucho tiempo en la pantalla de carga

  • La primera vez es normal que tarde. Esperar al menos 15 minutos antes de apagarlo.

Arranca leJOS pero da error de Java

  • Revisar que el archivo de Java sea la versión 7 Update 60 ARMv5, que termine en .tar.gz y que esté en la raíz. Volver a formatear y armar la tarjeta desde S1.

Para armar varias tarjetas

  • Guardar en la PC los dos archivos descargados y repetir S1, S2 y S4 con cada tarjeta. El archivo de Java es de Oracle y no se puede subir al repositorio público.
